# 調式綜合測驗 · 旋律換音,換調式 (Mode Change Quiz)

同一旋律骨架,後段換幾個音;聽出前段與後段各是哪個調式。10 題,答對 8 題及格,不限時。
同主音設計的調式聽辨綜合測驗,定位在調式練習系列教材最後。
